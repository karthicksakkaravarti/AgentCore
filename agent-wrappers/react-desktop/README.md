# agent-core React Desktop (Electron)

An Electron application that runs `@agent-core/core` in the main Node.js process and streams text deltas to a React renderer via IPC. Provides a native desktop chat interface with no server required.

---

## What It Does

- The Electron main process instantiates `AgentCore` and handles all LLM communication
- Text deltas are forwarded to the React UI via Electron IPC as they arrive
- A `contextBridge` exposes a typed `window.agentDesktop` API to the renderer (no `nodeIntegration`)
- The app runs in chat-only mode — no tools are enabled by design
- API key and model can be set via environment variables or typed directly into the UI

---

## Quick Start

```sh
cd agent-wrappers/react-desktop
npm install
npm run dev
```

Set a provider key before starting, or type it into the API key field in the app:

```sh
export ANTHROPIC_API_KEY="sk-ant-..."
# or
export OPENAI_API_KEY="sk-..."
export AGENT_CORE_MODEL="openai/gpt-4o"
```

The dev script builds `agent-core`, starts Vite at `http://127.0.0.1:5173`, and launches Electron once that port is ready.

## Architecture

```
React Renderer (Vite / browser context)
    │
    │  window.agentDesktop.run(payload, handlers)
    │  window.agentDesktop.getDefaults()
    ▼
contextBridge  (preload.ts — sandboxed bridge)
    │
    │  ipcRenderer.send("agent:run", { runId, ...payload })
    │  ipcRenderer.on("agent:delta:<runId>", ...)
    │  ipcRenderer.once("agent:done:<runId>", ...)
    │  ipcRenderer.once("agent:error:<runId>", ...)
    ▼
Electron Main Process  (main.ts — Node.js)
    │
    │  ipcMain.on("agent:run", ...)
    │  new AgentCore({ allowedTools: ["__none__"], persistSession: false, ... })
    │  agent.run(prompt)
    │  event.sender.send("agent:delta:<runId>", text)
    │  event.sender.send("agent:done:<runId>", { stoppedBy, usage })
    ▼
LLM Provider (Anthropic / OpenAI / etc.)
```

### Key files

| File | Role |
|---|---|
| `src/main.ts` | Electron main process; creates `AgentCore`, handles IPC |
| `src/preload.ts` | `contextBridge` that exposes `window.agentDesktop` to the renderer |
| `src/renderer/App.tsx` | React chat UI; calls `window.agentDesktop` |
| `src/renderer/global.d.ts` | TypeScript declaration for `window.agentDesktop` |

## IPC Protocol

Each `run()` call generates a unique `runId` (UUID). Event channels are namespaced by `runId` so concurrent runs do not interfere.

| Channel | Direction | Payload | Purpose |
|---|---|---|---|
| `agent:run` | renderer → main | `RunPayload` (see below) | Start an agent run |
| `agent:cancel` | renderer → main | `runId: string` | Abort an in-progress run |
| `agent:defaults` | renderer ↔ main | `{ model: string }` | Get default model from env |
| `agent:delta:<runId>` | main → renderer | `text: string` | One streamed text chunk |
| `agent:done:<runId>` | main → renderer | `{ stoppedBy, usage }` | Run completed successfully |
| `agent:error:<runId>` | main → renderer | `message: string` | Run failed or timed out |

### `RunPayload` shape

```ts
{
  runId: string;        // generated by preload
  prompt: string;       // user's message
  model?: string;       // e.g. "openai/gpt-4o" (overrides default)
  apiKey?: string;      // if not set via env var
  messages?: ChatMessage[];  // prior conversation history (last 20 kept)
}
```

## `window.agentDesktop` API

Exposed by `preload.ts` via `contextBridge.exposeInMainWorld("agentDesktop", ...)`.

```ts
interface AgentDesktop {
  // Returns the default model from process.env
  getDefaults(): Promise<{ model: string }>;

  // Starts a run; returns a cancel function
  run(
    payload: { prompt: string; model?: string; apiKey?: string; messages?: ChatMessage[] },
    handlers: {
      onDelta(text: string): void;   // called for each text chunk
      onDone(result: unknown): void; // called when run completes
      onError(message: string): void; // called on error or abort
    }
  ): () => void; // call this to cancel
}
```

## Configuration

### API key

Set via environment variable before launching:

```sh
export ANTHROPIC_API_KEY="sk-ant-..."
```

Or type it into the API key field in the app header. The field value is sent with each request payload as `apiKey`.

### Model

Set via environment variable:

```sh
export AGENT_CORE_MODEL="openai/gpt-4o"
# or
export ANTHROPIC_MODEL="claude-opus-4-7"
```

The app reads the default at startup via `agent:defaults`. The model field in the UI can be changed at any time; it is sent with each request.

### Run timeout

Hardcoded to **90 seconds** in `main.ts`:

```ts
const RUN_TIMEOUT_MS = 90_000;
```

To change it, edit that constant in `src/main.ts`.

## Why No Tools

`AgentCore` is instantiated with:

```ts
allowedTools: ["__none__"],
persistSession: false,
```

`"__none__"` is a sentinel value that results in an empty tool list. This is intentional — the desktop app is a pure chat interface. The agent answers questions but cannot read files, run commands, or access the web.

## Extending

### Enable tools

To enable specific tools, change `allowedTools` in `src/main.ts`:

```ts
const agent = new AgentCore({
  ...
  allowedTools: ["Read", "Glob", "Grep"],  // read-only tools
  runtime: new LocalRuntime(),             // import LocalRuntime from "@agent-core/core"
});
```

You will also need to add a workspace if you enable file tools:

```ts
import { LocalWorkspace } from "@agent-core/core";

const agent = new AgentCore({
  ...
  workspace: new LocalWorkspace({ cwd: payload.cwd ?? process.cwd() }),
  allowedTools: ["Read", "Glob", "Grep"],
  runtime: new LocalRuntime(),
});
```

### Enable session persistence

By default `persistSession: false` means transcripts are not saved. To enable:

```ts
import { FileSystemSessionStorage } from "@agent-core/core";

const agent = new AgentCore({
  ...
  persistSession: true,
  sessionStorage: new FileSystemSessionStorage(app.getPath("userData")),
});
```

### Add a new IPC channel

1. Add a handler in `src/main.ts`:

   ```ts
   ipcMain.handle("agent:clear", () => {
     // clear history, etc.
   });
   ```

2. Expose it in `src/preload.ts`:

   ```ts
   contextBridge.exposeInMainWorld("agentDesktop", {
     ...existing,
     clear: () => ipcRenderer.invoke("agent:clear"),
   });
   ```

3. Call it from `src/renderer/App.tsx`:

   ```ts
   await window.agentDesktop.clear();
   ```
